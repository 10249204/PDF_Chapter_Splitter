# PDF Chapter Splitter v1.0.0

PDF Chapter Splitter v1.0.0 is the first Windows desktop release.

## Download

Download:

```text
PDF-Chapter-Splitter-v1.0.0-windows-x64.zip
```

Unzip it, then double-click:

```text
PDF-Chapter-Splitter.exe
```

No Python, pip, Git, or PowerShell setup is required for normal users.

## Highlights

| Feature | Status |
| --- | --- |
| Windows desktop GUI | Included |
| PDF Outline / bookmark based chapter candidates | Included |
| Text layout based chapter candidates | Included |
| PDF text quality warning | Included |
| Human chapter confirmation | Included |
| Chapter title and start page editing | Included |
| PDF splitting | Included |
| Optional ZIP output | Included |

## Known Limits

| Limit | Notes |
| --- | --- |
| No OCR yet | Scanned PDFs may require manual chapter entry. |
| No AI / LLM / embedding | Chapter detection is deterministic and explainable. |
| Detection is not guaranteed | Users must confirm chapters before splitting. |
| No PDF preview yet | Use your PDF reader to verify physical page numbers. |
| No task cancellation yet | Analysis and splitting cannot be cancelled mid-run. |
